01Why rescaling cannot work

Both systems obey one two-parameter law v(y) = a·ec·y + b·e2c·y. The source is purely Poisson, so b = 0 exactly — it lies on the boundary of the family. Any target with electronic noise has b > 0. Move the sliders: no vertical shift of the source curve reproduces a target curve's shape.

source law (b = 0) target law best rescaling of the source

D = ⟨|log(vt/vs)|⟩ is the shift magnitude, averaged over the signal distribution. It is computable from the estimated law and the known source law, so it can be evaluated before adapting — with no labels.

02When adaptation helps — and when it hurts

Anatomy, geometry, sampling and reconstruction held fixed; only (I₀, σe) varied over a 4×4 grid. The gain is predicted by the full law mismatch D (ρ = 0.953), not by σe alone (ρ = −0.137, p = 0.61). Every point is a separately adapted and evaluated model.

The three failures are all low-mismatch cells (D < 1). The two real operating points sit at D = 2.09 (25% dose) and D = 1.05 (10% dose) — which is exactly why the 10% case fails. It is predicted, not anomalous.

Two columns go against us, and we report them. Undenoised FBP wins VIF outright — VIF penalises blur far more than noise, so on this data it ranks doing nothing above every denoiser. And the retrained supervised RED-CNN takes every pixel metric while posting the worst texture score of any method (NPS shape 2.43 vs NoLA's 0.89), keeping only 17% of full-dose noise power. Pixel metrics reward smoothing.

04An ablation that beats us

Removing NoLA's whiteness term improves every full-reference metric and degrades only texture and residual decorrelation. So we swept its weight to find out whether that was a badly chosen constant or a real frontier.

The cost is a step, not a slope: switching the term on at all costs ~0.2 dB and raising the weight tenfold costs no more, while decorrelation saturates by λ = 0.5. No weight buys it cheaply. There is a reason: the MMSE residual is provably not white (the Wiener residual spectrum σ⁴/(Ps(f)+σ²) is not flat), so enforcing whiteness must move away from MMSE — the same argument that made us drop the orthogonality term. We keep λ = 1, which is the most efficient point measured, and say plainly that a reader optimising PSNR alone should switch it off.

05Where it fails, and why that matters

At 10% dose NoLA reaches 36.68 dB against the source model's 40.55 — worse than doing nothing. It is not estimation error: the oracle-law variant fails identically (38.35 dB). The residual audit shows something sharper.

← better law matchhigher PSNR ↑

At 25% dose the objective and the image are not even monotonically related — supervised fine-tuning has the worst law match and the best image. At 10% the relationship inverts outright: NoLA attains the best law match (0.106) and the lowest residual autocorrelation (0.012) of any method, better than supervised fine-tuning, while producing the worst image. Matching the target's residual statistics does not identify the clean signal. That is the paper's own scope statement, made visible.

06Run it yourself

The demo needs no data download and no ASTRA. It builds a phantom, acquires it under two noise laws, trains a source denoiser, estimates the target law from unlabelled sinograms and adapts — calling the same modules used for every number above.

git clone https://github.com/mtliba/nola && cd nola
pip install -e ".[demo]"
python examples/demo.py

Reproducing the paper's numbers needs LoDoPaB-CT and the Mayo-2016 LDCT Grand Challenge data, which we cannot redistribute. See the README for the full pipeline — and for the warning that astra_cpu and astra_cuda differ by more than a decibel, so a single table must never mix them.
